nwa
network analysis - runs locally, nothing is uploaded

1 Run the script

irm https://raw.githubusercontent.com/SolusKossi/nwa/main/nwa.ps1 -OutFile nwa.ps1
powershell -ep bypass -f .\nwa.ps1

Shows live status while it runs. Press Q to stop - it builds and opens the report itself. Options: -Snapshot for a one-shot check, -Sites "yourapp.com" to also test your own sites.
